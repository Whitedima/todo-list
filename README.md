# Список задач (To-Do)

Простой сайт для списка дел. Тестовое задание.

## Что умеет

- Создавать задачи (кнопка или Enter, пустую задачу создать нельзя)
- Отмечать выполненные
- Удалять задачи
- Сохранять список после перезагрузки страницы (localStorage браузера)
- Фильтр: все, активные, готовые
- Счётчик «осталось выполнить» и кнопка «Очистить выполненные»
- Адаптивная вёрстка: компьютер и телефон

## Как запустить

Скачай папку и открой `index.html` в браузере. Сборка и установка не нужны

## Стек

HTML, CSS, JavaScript без библиотек и фреймворков

## Какие AI-инструменты применялись

- Claude Code (Anthropic): написание кода и проверка в браузере (Playwright)
